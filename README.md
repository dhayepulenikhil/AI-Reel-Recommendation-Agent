AI Reel Recommendation Agent
📌 Project Description

AI Reel Recommendation Agent is a Python-based Streamlit web application that analyzes anonymized student interaction history and identifies broader technology interests. Based on the detected interest, the system recommends useful technology-related Reel content.

🚀 Features
Instagram Reel URL validation
Student interaction history analysis
Technology interest detection
Interest confidence level
Personalized technical content recommendation
Simple and interactive Streamlit interface
Recommendation explanation
🛠️ Technologies Used
Python
Streamlit
